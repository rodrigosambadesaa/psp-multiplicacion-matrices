# Enunciado original — Multiplicación de matrices

Fuente: `EjercicioMatrices.pdf` de **Programación de Servicios y Procesos**.

Implementar primero un programa **secuencial** que calcule el producto de dos matrices grandes. A continuación, modificarlo para realizar la misma tarea mediante **varios hilos**, de forma que cada hilo se encargue de un subconjunto de la matriz resultado.

Finalmente, medir y comparar el tiempo empleado por la versión secuencial y la versión concurrente.

No existe una base de datos asociada a este ejercicio.
